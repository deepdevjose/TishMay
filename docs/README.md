# EsteticaApp Docs

Esta carpeta organiza la documentacion tecnica, funcional y de negocio de EsteticaApp.

## Indice

- `01_overview/project_overview.md`: contexto rapido del producto.
- `02_architecture/architecture.md`: arquitectura y decisiones tecnicas.
- `02_architecture/folder_structure.md`: estructura de paquetes y convenciones.
- `03_features/*.md`: documentacion funcional por modulo.
- `04_api/*.md`: modelo de datos Firebase y contratos.
- `05_setup/*.md`: instalacion y configuracion del entorno.
- `06_testing/testing_strategy.md`: estrategia de pruebas.
- `07_deployment/build_release.md`: proceso de build y release.
- `08_business/*.md`: modelo de negocio, costos y roadmap.
- `diagrams/*.md`: diagramas Mermaid para arquitectura, navegacion, datos, estados y modulos.

## Diagramas Mermaid

- `diagrams/architecture_diagram.md`: arquitectura del sistema.
- `diagrams/navigation_flow.md`: flujo de navegacion.
- `diagrams/data_flow.md`: flujo de datos extremo a extremo.
- `diagrams/app_states.md`: estados principales de la app.
- `diagrams/module_relations.md`: relaciones entre modulos.
- `diagrams/database_diagram.md`: entidades de datos y relaciones.

## Alcance

La documentacion esta orientada a tres objetivos:

1. Acelerar onboarding tecnico.
2. Estandarizar mantenimiento y evolucion del sistema.
3. Facilitar presentacion profesional del proyecto.
